# Skill Bridge Backend

Node.js + TypeScript API for assessments. Contract target for the Skill Bridge Next.js frontend (`NEXT_PUBLIC_API_URL`, default `http://localhost:3001`).

## Stack

- Express
- TypeScript
- PostgreSQL + Knex
- Route → Controller → Service → Model

## Setup

1. Copy env file and set `OPENROUTER_API_KEY`:

```bash
cp .env.example .env
```

Assessment reports are generated via OpenRouter (`OPENROUTER_MODEL`, default `openai/gpt-4o-mini`). The LLM returns the full `` JSON.

2. Ensure PostgreSQL is running and create the database if needed:

```bash
createdb skill_bridge
```

3. Install and migrate:

```bash
npm install
npm run migrate:latest
```

4. Start the API:

```bash
npm run dev
```

Health check: `GET http://localhost:3001/health`

## Endpoints

| Method | Path | Purpose |
|--------|------|---------|
| `POST` | `/services/s3/upload` | Upload PDF to S3; save metadata in `s3_files`; return file `id` |
| `POST` | `/assessments` | Create assessment from questionnaire (+ optional `resumeFileId`) |
| `GET` | `/assessments/:id` | Full assessment report |
| `POST` | `/assessments/:id/email` | Send report email via SMTP (Nodemailer) |

### Resume + assessment flow

1. `POST /services/s3/upload` with multipart field `file` (PDF)
2. Response includes `id` — send that as `resumeFileId` on `POST /assessments`
3. Backend looks up `s3_files`, creates a signed URL, downloads/extracts PDF content
4. Form answers + resume content are sent to OpenRouter for the final JSON report

Assessment report PDFs for candidates are still generated by the Next.js frontend, not this API.

Errors return `{ "error": "Human-readable message" }`.

Configure SMTP with `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, and `SMTP_FROM`.

Configure S3 with `AWS_REGION`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, and `AWS_S3_BUCKET`.
